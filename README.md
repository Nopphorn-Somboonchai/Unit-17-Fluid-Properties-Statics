## 📖 ภาพรวมโปรเจกต์ (Overview)

โปรเจกต์สื่อการสอนแบบโต้ตอบ (**Interactive Web Application**) ที่ถูกออกแบบมาเพื่อช่วยให้นักเรียนระดับชั้นมัธยมศึกษาปีที่ 6 เข้าใจคุณลักษณะเด่นของของไหลอย่างเห็นภาพชัดเจน:

* 💧 **คุณลักษณะของไหล**: ความตึงผิว ($\gamma$), ความหนืด ($\eta$)
* ⚖️ **กลศาสตร์ของไหลสถิต**: ความดันในของไหล ($P$), กฎของพาสคัลในเครื่องอัดไฮดโลริก, และแรงพยุงตามหลักของอาร์คิมีดีส ($B$)
* 🎯 **ระบบการเรียนรู้ 3 โหมด**: การจำลองภาพเสมือนจริง (Virtual Simulation), การฝึกทำโจทย์แบบสุ่มตามเลขที่ (Dynamic Quiz), และระบบสอบเก็บคะแนนแบบจับเวลา (Timed Exam)
* ⚡ **Single-File Architecture**: เปิดใช้งานผ่านเว็บเบราว์เซอร์ได้ทันที ไม่ต้องผ่านขั้นตอนการ Build

## ✨ ฟีเจอร์หลักของระบบ (Key Features)

### 1. 📖 ระบบทบทวนบทเรียนและเครื่องมือจำลอง (Interactive Review & Simulators)

* **Simulator 1: การวัดสัมประสิทธิ์ความตึงผิวด้วยห่วงวงกลมและคานสมดุล (Liquid Surface Tension)**
  * แอนิเมชันจำลองเครื่องมือวัดความตึงผิวแบบห่วงวงกลมดึงฟิล์มน้ำด้วยคานสมดุลตามหลักฟิสิกส์
  * สามารถปรับระยะตุ้มซ้าย $x$, ระยะห่วงขวา $y$, รัศมีของห่วง $R$, มวลของห่วง $m_{\text{ring}}$ และมวลของตุ้มน้ำหนัก $W$ ได้อย่างอิสระ
  * มีระบบค่อยๆ เลื่อนตุ้มน้ำหนักซ้าย $x$ หรือเพิ่มมวลตุ้ม $W$ อัตโนมัติเพื่อหาจุดฉีกขาดของฟิล์ม
  * คำนวณสัมประสิทธิ์ความตึงผิวจากการทดลองจริง $\gamma_{\text{exp}}$ ณ วินาทีที่ฟิล์มขาดสะบั้นโดยเปรียบเทียบกับค่าทฤษฎีตามชนิดของเหลว

* **Simulator 2: การตกของวัตถุทรงกลมภายใต้แรงหนืด (Viscosity & Stokes' Law)**
  * แอนิเมชันจำลองการปล่อยลูกกลมโลหะร่วงลงในหลอดทดลองบรรจุของของเหลวที่มีระดับความหนืดต่างกัน (น้ำผึ้ง, น้ำมันพืช, น้ำสะอาด)
  * แสดงเวกเตอร์ของแรงทั้งสามที่กระทำต่อวัตถุทรงกลมแบบเรียลไทม์: แรงโน้มถ่วง ($mg$), แรงพยุง ($B$), และแรงต้านความหนืด ($F_v$)
  * มีกราฟอัตราเร็ว-เวลา ($v-t$) แบบ Real-time ที่พล็อตโค้งลู่เข้าหา **ความเร็วปลายคงตัว (Terminal Velocity: $v_t$)**

* **Simulator 3: การแทนที่ปริมาตรและแรงพยุง (Buoyant Force & Archimedes' Principle)**
  * จำลองการหย่อนบล็อกวัตถุลงในน้ำล้น เพื่อวิเคราะห์แรงพยุงตามหลักอาร์คิมีดีส
  * แสดงขนาดน้ำล้นลงถ้วยตวงตามปริมาตรส่วนที่จมของบล็อกจริง ($V_{\text{sub}}$) พร้อมปุ่มกดกระตุ้นการกระเพื่อมสั่นไหว (Bob Block)

### 2. 🧠 ระบบตะลุยโจทย์เฉพาะตัว (Roll-Number-Based Practice System)

* **โหมดการเรียนรู้**: เลือกได้ระหว่างโจทย์ตัวเลขคงที่ (อิงตามคู่มือเรียน สสวท.) และโจทย์สุ่มตัวเลข (RNG)
* **หัวข้อคลังข้อสอบย่อย**:
  * `17.2.1` **ความตึงผิวของของเหลว**: หาค่าสัมประสิทธิ์ความตึงผิว ($\gamma = \frac{F}{L}$)
  * `17.2.2` **แรงหนืดและกฎของสโตคส์**: หาความหนืดหรือความเร็วปลาย ($F = 6\pi \eta r v$)
  * `17.3.1` **ความดันในของไหล**: คำนวณความดันเกจและความดันสัมบูรณ์ ($P = P_0 + \rho g h$)
  * `17.3.2` **เครื่องอัดไฮดรอลิก**: หาแรงยก/แรงกดตามกฎพาสคัล ($\frac{f}{a} = \frac{F}{A}$)
  * `17.3.3` **แรงพยุงของไหล**: คำนวณแรงพยุงและหลักอาร์คิมีดีส ($B = \rho V g$)
* **ระบบเฉลยละเอียด**: แสดงผลการตรวจคำตอบทันทีพร้อมวิธีทำคำนวณสูตรฟิสิกส์ทีละขั้นตอนอย่างละเอียดในรูปแบบอักษรคณิตศาสตร์ที่สวยงาม ($\text{\LaTeX}$)

### 3. ⏱️ ระบบสอบเก็บคะแนน (Timed Exam System)

* **ระบบจำลองการสอบแบบจำกัดเวลา**: จำนวน 5 ข้อ (คะแนนเต็ม 10 คะแนน) โดยมีระยะเวลาจำกัดในการทำข้อสอบ **15 นาที** พร้อมตัวจับเวลาถอยหลัง (*Timer*) ในแถบเมนูด้านบน
* **การสอบแบบผสมผสาน**: ระบบจะสุ่มข้อสอบโดยมี **ข้อสอบแบบเลือกตอบ (Choice) 1 ข้อ** และ **ข้อสอบแบบคำนวณตัวเลข (Numeric Input) 4 ข้อ** เพื่อวัดผลทั้งความเข้าใจเชิงทฤษฎีและทักษะการคำนวณเกี่ยวกับของไหลสถิตอย่างรอบด้าน
* **ระบบป้องกันการโกง (Anti-cheat guard)**: แจ้งเตือนและป้องกันการรีเฟรชหน้าจอหรือออกจากหน้าสอบโดยไม่ตั้งใจ
* **Dashboard สรุปผล**: แสดงคะแนนรวม เวลาที่ใช้ พร้อมตารางสรุปสถานะการตอบแต่ละข้อ และปุ่มดูเฉลยละเอียดวิธีคิดอย่างเป็นขั้นเป็นตอน
* **ระบบบันทึกผลคะแนน**: บันทึกผลสอบล่าสุดเก็บไว้ใน `LocalStorage` ของเบราว์เซอร์ เพื่อให้ผู้เรียนสามารถตรวจสอบคะแนนล่าสุดได้ที่หน้าแรก

## 🎯 กฎระบบข้อสอบแปรผัน (Dynamic Quiz System Rules)

> [!IMPORTANT]
> ระบบข้อสอบในโปรเจกต์นี้ได้รับการออกแบบให้เป็น **Non-Deterministic Dynamic System** โดยผูกค่าตัวแปรในโจทย์เข้ากับ **"เลขที่ของนักเรียน (Roll Number: $R$)"** เพื่อให้มั่นใจว่านักเรียนแต่ละคนจะได้รับพารามิเตอร์โจทย์และคำตอบสุดท้ายที่ไม่ซ้ำกัน

1. **Dynamic Parameter Generation**: ระบบจะดึงเลขที่ของนักเรียน ($R$ ตั้งแต่ 1-40) มาคำนวณร่วมกับฐานตัวแปรที่ถูกสุ่มขึ้นมาแบบอิสระ (*Non-deterministic Random*) เช่น $P = P_{\text{base}} + R$ หรือการบวกค่าเลขที่เข้าไปในปริมาตรความลึก เพื่อสร้างค่าพารามิเตอร์ชุดใหม่สำหรับโจทย์แต่ละข้อ
2. **On-the-fly Validation**: การประเมินคำตอบและเฉลยวิธีทำจะคำนวณแบบสด ๆ (*On-the-fly*) จากเลขที่ $R$ ของผู้เข้าสอบจริง โดยไม่ใช้ค่าคงที่ตายตัว (*No Static Hardcoded*)
3. **Safety Constraints**: สมการเบื้องหลังได้รับการกำหนดขอบเขตค่าต่ำสุด-สูงสุดไว้อย่างรัดกุม เพื่อป้องกันไม่ให้การคำนวณร่วมกับเลขที่ $R$ เกิดค่าที่ติดลบหรือไม่สมเหตุสมผลทางฟิสิกส์

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* **HTML5**: จัดวางโครงสร้างและเนื้อหาเว็บแอปพลิเคชันตามมาตรฐาน Semantic HTML
* **Vanilla CSS (`style.css`)**: การตกแต่งเพิ่มเติม เช่น แอนิเมชันกระบอกสูบ ปรับแต่ง Scrollbar และเอฟเฟกต์การตอบสนองของปุ่มต่าง ๆ
* **JavaScript (ES6+ / `app.js`)**: ลอจิกควบคุมทั้งหมด ระบบคำนวณฟิสิกส์ อัลกอริทึมการสุ่มและตรวจข้อสอบ ตัวจับเวลา และการพ่นกราฟบน HTML5 Canvas
* **Tailwind CSS (via CDN)**: จัดการ UI/UX, สีสัน, รูปแบบ Grid/Flex Layout และความ Responsive รองรับทั้งคอมพิวเตอร์ แท็บเล็ต และสมาร์ทโฟน
* **KaTeX (via CDN)**: ไลบรารีประสิทธิภาพสูงสำหรับเรนเดอร์สมการคณิตศาสตร์และสูตรฟิสิกส์ด้วยฟอร์แมต $\text{\LaTeX}$
* **Lucide Icons**: บริการไอคอนเวกเตอร์สำหรับแสดงสัญลักษณ์และเมนูในหน้าเว็บ
* **Google Fonts**: ฟอนต์ `Prompt` และ `Sarabun` อ่านง่าย ดูสวยงามและมีความเป็นสากล

## 🚀 วิธีการใช้งาน (How to Run)

> [!TIP]
> ไม่จำเป็นต้องติดตั้ง Node.js หรือผ่านกระบวนการ Build ใดๆ สามารถรันผ่านเว็บเบราว์เซอร์ได้ทันที

1. **ดาวน์โหลด หรือ Clone Repository** ลงบนเครื่องคอมพิวเตอร์ของคุณ
2. ตรวจสอบให้มั่นใจว่าไฟล์ `index.html`, `app.js`, `style.css` และไฟล์ประกอบทั้งหมดวางอยู่ในไดเรกทอรีเดียวกัน
3. ดับเบิลคลิกเปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์หลัก (เช่น Google Chrome, Microsoft Edge, Safari) หรือรันผ่าน **Live Server** บน VS Code
4. **การเชื่อมต่ออินเทอร์เน็ต**: จำเป็นต้องใช้อินเทอร์เน็ตในการโหลดตัวอักษร Google Fonts และไลบรารี CDN (Tailwind CSS, KaTeX, Lucide Icons)
